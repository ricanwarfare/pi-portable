# Pi Portable v0.3.0

Adds a Linux x64 executable alongside the Windows EXE, with the same Ollama Cloud / DeepSeek 4.1 Flash preset and saved-key setup.

```bash
sha256sum -c pi-portable-linux-x64.sha256
chmod +x pi-portable-linux-x64
./pi-portable-linux-x64
```

The first interactive launch prompts for a hidden API key and starts Pi after saving it. The same `pi-portable-data/agent/ollama-cloud.key` layout works on both platforms. Keys remain plaintext: protect your response drive. Linux requests owner-only permissions where the filesystem supports them.

The Linux executable embeds official Pi 1.3.0, ripgrep 15.2.0, and fd 10.5.0. It extracts and verifies its runtime beside the executable by default, uses Bash instead of PowerShell, and needs no Node.js, Bun, Python, Go, or local Ollama installation on the target. Bash and compatible glibc Linux are required. CI validates Ubuntu 22.04 and 24.04 x64, including real terminal setup/cancellation and actual tools against a localhost fake model.

Both the executable and extracted runtime must be on filesystems permitting execution. Use `PI_PORTABLE_HOME` to choose a writable, executable data location. ARM64 and Alpine/musl are not supported by this artifact. Windows launch behavior and icon are unchanged.

Download the executable for your platform and its matching `.sha256`; `.build.json` records dependency/source provenance. Existing data folders are preserved. This remains an unsigned, self-extracting tool, with no sandbox or forensic write-blocking guarantees. Cloud inference sends included prompts and tool results to the selected provider.
