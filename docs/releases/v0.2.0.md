# Pi Portable v0.2.0

Copy the EXE to your response drive and run it. On the first interactive Ollama Cloud launch, paste your API key into the hidden-input prompt and press Enter. Pi starts automatically. Later launches reuse the saved key.

- Hidden entry with backspace support; Escape/Ctrl+C cancels without saving.
- `--portable-setup` replaces the launcher-saved key.
- `OLLAMA_API_KEY` overrides the saved value without modifying the file.
- No automatic prompt for redirected streams, RPC, utility commands, other providers, resumed sessions, or existing Pi credentials.
- Saved-key authentication tested with real Pi tools against a localhost fake model; hidden-input behavior tested separately.

**The key is stored in plaintext at `pi-portable-data/agent/ollama-cloud.key` so it works across Windows systems. Protect your drive and do not share that file.** Pi's own credentials in `auth.json` take precedence; manage them through `/login` and `/logout`. Keys are not embedded in the release, echoed by the setup prompt, or passed as command-line arguments. Setup does not make a cloud request to validate the key.

Windows x64; upstream Pi 1.3.0, ripgrep 15.2.0, fd 10.5.0, Ollama Cloud / DeepSeek 4.1 Flash. The unsigned, self-extracting architecture and incident response boundaries remain unchanged.
