# Pi Portable v0.1.0

Initial public release of **Pi Portable**, an Incident Response distribution fork of the [Pi coding agent](https://github.com/earendil-works/pi).

One distributable Windows x64 EXE contains official, unmodified Pi 1.3.0, its assets, ripgrep 15.2.0, and fd 10.5.0. The launcher extracts and verifies the runtime, keeps state in a portable home, and enables PowerShell/file/search tools by default.

## Start

Download `pi-portable.exe` and `pi-portable.exe.sha256`, verify the hash, and run:

```powershell
$env:OLLAMA_API_KEY = '<your-api-key>'
.\pi-portable.exe
```

Ollama Cloud / `deepseek-v4.1-flash` is preconfigured. No local Ollama, Node.js, Bun, npm, or Git Bash is required. The target needs .NET Framework 4.8, Windows PowerShell, provider access, and a writable portable home.

## Included

- Portable configuration, sessions, temporary files, and `PI_PORTABLE_HOME` override.
- Embedded provider presets referencing the environment key, preserving existing config.
- Runtime integrity checks, archive/junction checks, and concurrent extraction locking.
- Disabled startup downloads, telemetry, workspace discovery, and MCP for normal launches.
- SHA256 sidecar and `pi-portable.exe.build.json` with source/dependency provenance.

## Validation and limits

Nine launcher tests and the runtime smoke test cover argument forwarding, stdin, exit codes, state paths, integrity checks, configuration preservation, default DeepSeek selection, Bearer authentication, and real PowerShell/read/search tools using a localhost fake model. CI uses no cloud credentials.

This initial release is unsigned and self-extracting. It is not a sandbox, write blocker, or zero-artifact tool. Prompts and included tool results go to the selected cloud provider. Live Ollama access, clean-VM compatibility, and interactive behavior need further validation. Windows x64 is the only current target.

See the README for usage, evidence handling, attribution, and troubleshooting.
