# Pi Portable v0.2.1

Adds an original Pi shield icon embedded in the Windows executable. The icon includes seven sizes from 16 to 256 pixels; no companion icon file is needed on your USB drive. SVG source and a Windows PowerShell generation script are included in the repository.

You can double-click `pi-portable.exe` in File Explorer. It opens a console, prompts for your Ollama Cloud API key when needed, and starts Pi. It remains a terminal application. The working directory will normally be the executable's folder; launch from PowerShell or configure a shortcut's **Start in** field to select another investigation directory.

Replace the EXE on your USB and keep `pi-portable-data` to preserve your key and sessions. Windows may retain the previous icon in its Explorer cache until the folder is refreshed.

Authentication, upstream Pi 1.3.0, bundled search tools, and incident response behavior are unchanged. Saved keys remain plaintext on the portable drive; protect your drive.
