# Project maintenance

- Review README.md for every change and update it whenever behavior, commands, configuration, prerequisites, release status, or limitations change. Keep examples consistent with both launchers and version.json.
- Keep related documentation and CHANGELOG.md current. Describe the final behavior and distinguish published features from proposed work.
- Preserve attribution to the upstream Pi coding agent and the unmodified vendored packages.
- Never commit credentials, case evidence, sessions, generated executables, or build caches. Use synthetic data for tests.
